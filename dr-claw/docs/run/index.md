## Quick reference: agent states

| State | Meaning |
|---|---|
| `RUNNING` | Agent is healthy and accepting requests |
| `STARTING` | Workload spinning up (30–90 s) |
| `STOPPED` | Gracefully halted; restartable |
| `FAILED` | Workload crashed; check Logs tab |
| `PENDING_HITL` | Paused waiting for human approval |
